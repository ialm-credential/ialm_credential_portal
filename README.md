# IALM Gift Website

A static, fictional credential-verification microsite for a personal gift.

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server.

## Publish for free

GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Repository → Settings → Pages.
4. Select "Deploy from a branch", choose `main` and `/root`.
5. Save.
6. GitHub will give you an HTTPS URL.

Then put that URL into the QR code on the physical credential.

## Important

The IALM organization and credential are fictional and intended only as a personal gift.
